# TextPad - текстов редактор (State и Command)

Текстов редактор на Java (Swing), в който всяка промяна по текста е отделна команда, която може да
бъде отменена и върната. Текст може да се пише директно или да се вмъкне на точна позиция, а маркиран
участък може да се изтрие, копира, изреже или оцвети. Как реагира редакторът зависи от това в какво
състояние е - без селекция, със селекция или само за четене.

- **Command** - всяко действие е обект с `execute()` и `undo()`; `CommandManager` пази историята (Undo/Redo).
- **State** - редакторът е в едно от трите състояния: `NoSelectionState`, `SelectionState`, `ReadOnlyState`.
  Едни и същи клавиши правят различни неща според състоянието.
- **Observer** (допълнителен шаблон) - полето с текста, панелите, бутоните и лентата за състоянието горе
  се обновяват сами при всяка промяна.
- **Графичен интерфейс** - Swing с мек пастелен дизайн в синьо и оранжево (клас `Theme`), шрифт Nunito,
  заоблени карти, линейни икони, номера на редовете, директно писане в полето, лента горе с позицията
  (ред, позиция, селекция) и панел "История на командите" вдясно.

## Стартиране

**IntelliJ IDEA:** File → Open → папката `ST-Project`. Ако излезе "Project JDK is not defined", натиснете
Setup SDK и изберете инсталирания JDK (Java 17 или по-нова). После стартирайте `src/Main.java`.

**Команден ред** (от папката `ST-Project`):

```
javac -encoding UTF-8 -d out --source-path src src/Main.java
java -cp out;src Main          (на Linux/macOS: -cp out:src)
```

`src` е в classpath-а, за да се намери шрифтът от `src/ui/fonts`.

## Работа с програмата

| Действие | Как |
| --- | --- |
| Писане | направо в полето; Enter, Tab, Backspace и Delete работят както обикновено |
| Селекция | с мишката, Shift+стрелки, Ctrl+A или полетата "Позиция" и "Дължина" вдясно |
| Добавяне на дадена позиция | панел "Операции по позиция": позиция + текст → "Добави текста" (Ctrl+Enter) |
| Изтриване / копиране / изрязване / поставяне | Delete, Ctrl+C, Ctrl+X, Ctrl+V или бутоните горе (− изтрива, + поставя) |
| Оцветяване (добавяне / премахване на фон) | Ctrl+M / Ctrl+Shift+M (оранжев фон) |
| Отмяна / възвръщане | Ctrl+Z / Ctrl+Y |
| Само за четене | Ctrl+R или катинарът горе вдясно |
| Файлове | Ctrl+N нов, Ctrl+O отваряне, Ctrl+S запазване |
